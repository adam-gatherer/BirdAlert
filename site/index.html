Under the hood

Built for a dependable data path.

Every 15 minutes, EventBridge starts a Lambda poll of the eBird feed. Raw responses land in private S3, are validated and deduplicated, then become queryable DynamoDB records. API Gateway and CloudFront keep the public experience lightweight, while Terraform defines the stack end to end.

BirdAlert is an independent UK bird-sighting project. View the project on GitHub
